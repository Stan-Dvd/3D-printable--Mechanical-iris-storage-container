## Storage container with mechanical iris closing mechanism
The basic idea of the project is to create a circular container with a rotating lid that opens and closes an iris mechanism of some form, upon rotating the lid. The iris could be a simple "flat" iris with multiple blades that open/close or it could be a mechanism which includes a little verticality, as can be seen in some references below.
